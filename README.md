# 연성대 AVR 중간고사 예제 (ATmega128)

ATmega128 실습 보드(7.3728MHz)용 예제 6개. 각 폴더의 `.c` 파일을 AVR Studio 새 프로젝트(AVR GCC, `atmega128`)에 넣어 빌드한다. 6개 모두 avr-gcc(WinAVR)로 컴파일되는 것을 확인했다.

## 보드 배치

예제 전체가 쓰는 핀을 합친 최소 구성이다.

| 자원 | 핀 | 용도 |
|---|---|---|
| 버튼 | PF0 ~ PF3 | 누르면 1로 읽힘 |
| LED | PA0 ~ PA3 | 1 = 켜짐 |
| FND 세그먼트 | PORTC (8비트, bit7 = 소수점) | `0x3f`(0), `0x06`(1) ... |
| FND 자리 선택 | PG0 ~ PG3 | LOW인 자리가 켜짐 (active-low) |

- 타이머: Timer2 CTC 모드, 분주 1024, `OCR2 = 71` → 7,372,800 / 1024 / 72 = 100Hz (정확히 10ms)
- 3, 5, 6번은 PORTD(AM/PM 전용 FND)와 PA4 ~ PA7도 출력으로 설정하고 끄지만 기능에는 필요 없다.

## 예제

| 폴더 | 동작 | 사용 핀 |
|---|---|---|
| `1_LED_Hold` | 버튼을 누르는 동안 LED ON | PF0~PF3 → PA0~PA3 |
| `2_LED_Toggle` | 버튼을 누를 때마다 LED 토글 | PF0, PA0 |
| `3_FND_0to9` | 버튼을 누를 때마다 FND 0 ~ 9 순환 (오른쪽 끝 한 자리 고정) | PF0, PORTC, PG3 |
| `4_CTC_Blink` | Timer2 CTC 모드로 LED 0.5초마다 토글 | PA0 |
| `5_Stopwatch` | 스톱워치. PF0 시작/정지, PF1 리셋(정지 중), PF2 표시 전환(`SS.CC` ↔ `MM.SS`) | PF0~PF2, PORTC, PG0~PG3 |
| `6_Clock` | 12시간제 시계. 초기 → AM/PM → 시 → 분 → 동작. PF0 다음 단계, PF1 값 증가 | PF0~PF1, PA0~PA1, PORTC, PG0~PG3 |

## 코드 설명

### 1. `1_LED_Hold` : 누르는 동안 LED ON
```c
DDRF = 0x00;                // 버튼 입력
DDRA = 0xFF;                // LED 출력
while(1)
    PORTA = PINF & 0x0F;    // 버튼 상태를 그대로 LED에 출력 (레벨 방식)
```
상태를 저장하지 않아서 버튼을 떼면 바로 꺼진다.

### 2. `2_LED_Toggle` : 누를 때마다 토글
```c
Qa = PINF & 0x01;
if((Qa & 0x01) != 0 && (Qb & 0x01) == 0)    // 상승 에지
    LED = !LED;
PORTA = LED;
Qb = Qa;
```
`Qa`는 지금 버튼 값, `Qb`는 이전 값이다. 이전에는 0, 지금은 1인 순간(눌린 순간)에만 `LED`를 반전한다. 디바운스가 없어서 접점이 떨리면 한 번 눌러도 여러 번 바뀔 수 있다.

### 3. `3_FND_0to9` : FND 숫자 0 ~ 9
- `PORTG = 0x07`은 PG3만 LOW라서 오른쪽 끝 자리만 선택한다. 루프 밖에서 한 번만 설정하므로 자리는 고정이다.
- 버튼의 상승 에지마다 `FND`를 1 증가시키고 9 다음은 0으로 돌아간다. `ss_data[FND]`를 PORTC에 출력한다.
- 한 자리만 켜므로 스캔이 필요 없고, 디바운스는 없다.

### 4. `4_CTC_Blink` : CTC 모드 LED 점멸
```c
TCCR2 = (1<<WGM21) | (1<<CS22) | (1<<CS20);   // CTC 모드, 분주 1024
OCR2  = 71;                                   // 10ms
TIMSK = (1<<OCIE2);                           // 비교 일치 인터럽트 허용

ISR(TIMER2_COMP_vect)
{
    csec++;
    if(csec >= 50) { csec = 0; LED = !LED; }  // 50틱 = 0.5초
}
```
`main`은 시간을 세지 않고 `LED` 값에 따라 PA0만 갱신한다. ISR과 `main`이 같이 쓰는 변수는 `volatile`로 선언했다.

### 5. `5_Stopwatch` : 스톱워치
- **시간 계산(ISR)**: 10ms마다 `running`이면 `sw_csec`를 올리고, 100이면 초, 60이면 분으로 올림한다. 분은 60에서 0으로 돌아간다. 같은 ISR에서 `debounce`도 줄인다.
- **버튼(main)**: 상승 에지 + `debounce`(100ms). PF0 시작/정지, PF1 리셋(정지 중일 때만), PF2 표시 전환.
- **표시(main)**: 루프를 한 번 돌 때마다 한 자리씩 켠다(다이내믹 스캔). 자리를 바꾸기 전에 `PORTG = 0x0F`로 전체를 꺼서 잔상을 막는다. 두 번째 자리에는 `seg |= 0x80`으로 구분 소수점을 켠다.

### 6. `6_Clock` : 12시간제 시계
| status | 단계 | PF0 | PF1 | 깜빡임 |
|---|---|---|---|---|
| 0 | 초기 (시계 정지) | → 1 | - | FND 전체, PA1 LED |
| 1 | AM/PM 설정 | → 2 | AM/PM 반전 | 없음 |
| 2 | 시 설정 | → 3 | 시 + 1 | 시 두 자리 |
| 3 | 분 설정 | → 4 | 분 + 1 | 분 두 자리 |
| 4 | 동작 | → 1 | - | 없음 (PA0 LED 0.5초 점멸) |

- 시간은 `status == 4`일 때만 ISR에서 올라간다. 시가 11에서 12가 될 때 AM/PM이 바뀌고, 13이 되면 1로 돌아간다. 시작은 12시 AM이다.
- PA0은 동작 중 0.5초 점멸, PA1은 AM이면 켜진다(AM/PM 표시).
- 시·분 설정 중 버튼을 누르고 있는 동안은 계속 켜져 있고, 버튼을 떼면 깜빡임이 켜진 상태부터 다시 시작한다.
- 시 십의 자리가 0이면 꺼서 앞자리 0을 숨긴다.
